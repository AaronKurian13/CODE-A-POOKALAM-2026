## 🎨 My Pookalam

### Description

This Pookalam is built with Python Turtle as a layered radial artwork for Onam. The design uses concentric circles, geometric sector patterns, repeated triangle bands, decorative border rings, diyas, and a central sunflower created with a phyllotactic spiral.

Every layer is generated through code, turning angles, radii, color palettes, and repeated shapes into a complete digital flower carpet.

### Features

- Colorful geometric Pookalam generated using Python Turtle.
- Multiple concentric layers with circular, triangular, and radial sector patterns.
- Decorative outer border and diya ring.
- Phyllotactic sunflower placed at the center of the design.
- Fullscreen Turtle rendering for better viewing.

## 🚀 How to Run

### Prerequisites

Python 3.x is required. The project uses Python's built-in `turtle` module, so no external packages are needed.

### Running the Code

```bash
python3 main.py
```
